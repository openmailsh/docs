Add one URL to your client and your agent gets tools to create an inbox, read threads, and reply. Sign in with OAuth or an API key. No CLI or SDK install.

## Connect

<Tabs>
  <Tab title="Claude (OAuth)">
    In Claude, go to **Settings → Connectors → Add custom connector** and fill in:

    | Field | Value |
    | --- | --- |
    | URL | `https://mcp.openmail.sh/mcp` |
    | Authentication | **Sign in now** |
    | OAuth client | **Use Claude's published identity** (or **Register automatically**) |
    | Request headers | none |

    Click **Connect**. The console opens, you sign in, and the consent page shows the client name and host. If you belong to more than one organisation, pick the one the agent should use. **Read** is always granted; untick **Send**, **Setup**, or **Domains** if the agent should not have them. You can revoke the connection later under **Console → Settings → MCP**.

    Custom connectors need a Claude Pro, Max, Team, or Enterprise plan.
  </Tab>
  <Tab title="ChatGPT (OAuth)">
    Turn on **Settings → Apps & Connectors → Advanced → Developer mode**, then **Create** and fill in:

    | Field | Value |
    | --- | --- |
    | Name | OpenMail |
    | MCP server URL | `https://mcp.openmail.sh/mcp` |
    | Authentication | **OAuth** |

    Leave the client id and secret empty: ChatGPT identifies itself with its published client metadata, and the consent page shows `chatgpt.com` as the host. Sign in, choose an organisation, and untick any scopes the agent should not have.

    Developer mode is available on Plus, Pro, Business, Enterprise, and Edu plans.
  </Tab>
  <Tab title="Cursor / API key">
    Add to `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "openmail": {
          "url": "https://mcp.openmail.sh/mcp",
          "headers": { "Authorization": "Bearer om_YOUR_KEY" }
        }
      }
    }
    ```

    Prefer an inbox-scoped key. Create one in the console or with `openmail inbox keys create`. The key is sent as a header, never in the URL.
  </Tab>
  <Tab title="stdio-only clients">
    Bridge with `mcp-remote`:

    ```json
    {
      "mcpServers": {
        "openmail": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://mcp.openmail.sh/mcp"]
        }
      }
    }
    ```
  </Tab>
</Tabs>

Without a credential, `/mcp` answers `401` so your client starts the sign-in flow. For an agent that only needs to read these docs, use `https://mcp.openmail.sh/mcp/public`: no sign-in, just `search_docs` and `get_docs`.

## First run

Ask your agent: *"Set up an inbox for this agent and show me the address."*

It calls `setup_agent_email`, which returns a plan first. Confirm, and it creates the inbox and mints an inbox-scoped key. The key appears once in the tool result. Move it to the agent's environment and revoke it from the console if the transcript is shared.

## Tools

| Tool | What it does |
| --- | --- |
| `search_docs`, `get_docs` | Search and read these docs. Also available without sign-in at `/mcp/public`. |
| `auth_me` | Which customer and inbox this credential can see. |
| `setup_agent_email` | Plan, then create an inbox and mint a scoped key. |
| `list_inboxes`, `get_inbox`, `create_inbox`, `mint_inbox_key` | Inbox management. |
| `list_unread_threads` | Unread threads whose latest message is `autoReplyable`: sent by a person or another agent. Spam, marketing, bounces, and machine-generated mail (no-reply, OTPs, receipts) are filtered out. |
| `read_thread` | Full thread as Markdown with timestamps, `autoReplyable` flags, and attachment message ids. Quoted reply history is stripped. |
| `reply_to_thread`, `send_email` | Reply in-thread, or start a new one. `send_email` names the inbox it used when you did not pass `inbox_id`. |
| `mark_thread_read` | Mark a thread handled. |
| `get_attachment_text` | Extracted text from an attachment. Use the `message:` id shown in `read_thread`. |
| `list_domains`, `add_domain`, `get_domain`, `verify_domain` | Custom domains with pasteable DNS records. Pro plan. |
| `send_mcp_feedback` | Report a confusing or broken tool to the OpenMail team. |

Tools follow the credential. An inbox-scoped key hides `list_inboxes`, `setup_agent_email`, and the domain tools.

## Narrow what the agent can do

| Goal | URL |
| --- | --- |
| Read only, no sending | `https://mcp.openmail.sh/mcp/readonly` or `?readonly=true` |
| One inbox, no discovery | `https://mcp.openmail.sh/mcp/inbox/INBOX_ID` |
| Fewer tools | `?toolsets=mailbox,docs` or the `X-MCP-Toolsets` header |

## Example prompts

- Set up an inbox for this agent and show me the address.
- Reply to my unread mail.
- Read the invoice attached to the latest thread and summarize it.
- Add and verify `mail.example.com`.
