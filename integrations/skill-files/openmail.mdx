The skill lives in the skills repo at [`skills/openmail/SKILL.md`](https://github.com/openmailsh/skills/blob/main/skills/openmail/SKILL.md). It covers sending, replying in-thread, checking for new mail, attachments, policy, and pods.

**OpenClaw** — the [`@openmail/openclaw`](https://github.com/openmailsh/openclaw-plugin) plugin bundles its own copy, adapted to run commands as `openclaw openmail -- <command>`. Nothing to install separately. See [OpenClaw](/integrations/openclaw).

**Claude Code, Cursor, Codex** — install with `npx skills add openmailsh/skills`, or copy the file into `~/.claude/skills/openmail/` (or your agent's skills directory). See [Claude Code](/integrations/claude-code).
