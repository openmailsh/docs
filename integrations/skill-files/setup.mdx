# OpenMail Setup

## OpenClaw

```bash
openclaw plugins install clawhub:@openmail/openclaw
openclaw channels add --channel openmail --api-key <key>
openclaw gateway restart
```

The plugin bundles the CLI and the skill. See [OpenClaw](/integrations/openclaw) for modes, pod accounts, and configuration.

## Claude Code, Cursor, Codex

```bash
npm install -g @openmail/cli
export OPENMAIL_API_KEY=om_...
openmail init --mailbox-name my-agent --display-name "My agent"
npx skills add openmailsh/skills
```

- `init` creates your inbox and saves it as the default
- `npx skills add` installs the skill; or copy `skills/openmail/SKILL.md` from the [skills repo](https://github.com/openmailsh/skills) into `~/.claude/skills/openmail/`

## Requirements

- Node.js 20+
- An OpenMail account (free at [console.openmail.sh](https://console.openmail.sh/login), no credit card)

## Verify

```bash
openmail inbox list
```

## Multiple inboxes

To create additional inboxes:

```bash
openmail inbox create --mailbox-name "support" --display-name "Support"
```

## Remove

Delete `~/.openmail-cli/state.json` and the skill directory. For OpenClaw, remove the `channels.openmail` block from `openclaw.json` and uninstall the plugin.
