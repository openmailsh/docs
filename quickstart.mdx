Get your AI agent its own email address.

## Prerequisites

- [OpenMail account](https://console.openmail.sh/login) (free, no credit card)
- An API key from the [console](https://console.openmail.sh/api-keys)
- Node.js 20+ for the CLI path

<Tabs>
  <Tab title="OpenClaw">
    <Steps>
      <Step title="Install the plugin">
        ```bash
        openclaw plugins install clawhub:@openmail/openclaw
        ```
      </Step>
      <Step title="Add the channel">
        ```bash
        openclaw channels add --channel openmail --api-key <key> --mailbox-name my-agent
        openclaw gateway restart
        ```
        With an account key, `channels add` creates the inbox, mints an inbox-scoped key for it, and stores only that. Omit `--mailbox-name` to use an inbox you already have.
      </Step>
      <Step title="Check it">
        ```bash
        openclaw channels status
        ```
        Mail to `my-agent@omail.sh` now wakes the agent, and its reply goes out in the same thread.
      </Step>
    </Steps>

    Modes, pod accounts, and the configuration reference are in the [OpenClaw integration](/integrations/openclaw) guide.
  </Tab>
  <Tab title="Claude Code">
    <Steps>
      <Step title="Install the CLI">
        ```bash
        npm install -g @openmail/cli
        export OPENMAIL_API_KEY=om_...
        ```
      </Step>
      <Step title="Create an inbox">
        ```bash
        openmail init --mailbox-name my-agent --display-name "My agent"
        ```
        Creates the inbox and saves it as the default, so later commands need no `--inbox-id`.
      </Step>
      <Step title="Install the skill">
        ```bash
        npx skills add openmailsh/skills
        ```
        Or copy [`skills/openmail/SKILL.md`](https://github.com/openmailsh/skills/blob/main/skills/openmail/SKILL.md) into `~/.claude/skills/openmail/`. The same file works for Cursor and Codex; use your agent's skills directory.
      </Step>
    </Steps>

    Ask Claude Code to send a test email to confirm. Details in the [Claude Code integration](/integrations/claude-code) guide.
  </Tab>

  </Tab>

## Narrow the agent's key

An account-wide key reaches every inbox on your account. Give the agent an [inbox-scoped key](/concepts/inboxes#inbox-scoped-api-keys) instead, so a compromised agent can reach nothing but its own inbox.

The OpenClaw plugin does this for you: `channels add` mints an inbox-scoped key and never stores the account key. For the CLI path, mint one yourself and put it in `OPENMAIL_API_KEY`:

```bash
openmail inbox keys create --inbox-id <inbox-id> --name my-agent --json
```

The token is shown once. Minting needs your account-wide key, so run this from your own shell, not the agent's.

## More commands

```bash
openmail send --to hello@example.com --subject "Hello" --body "I have my own inbox!"
openmail send --to hello@example.com --subject "Report" --body "See attached" --attach report.pdf
openmail threads list --is-read false
openmail threads get --thread-id <thread-id>
```
