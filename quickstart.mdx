- An API key from the [console](https://console.openmail.sh/api-keys)

## Narrow the agent's key

An account-wide key reaches every inbox. Give the agent an inbox-scoped key instead, so a compromised agent can reach nothing but its own inbox. The OpenClaw and Hermes plugins do this during setup; for the CLI and API paths, mint one yourself. See [Scope the agent's key](/best-practices/api-key-scopes).
